## 6. 数据流分类 (完整请求链路)

```
Request
  │
  ▼
┌─────────────────────────────────────────────────────────────────────────┐
│  1. 输入层：POST /chat → {"question": "..."}                           │
│     backend/main.py 接收请求                                              │
└─────────────────────────────────────────────────────────────────────────┘
  │
  ▼
┌─────────────────────────────────────────────────────────────────────────┐
│  2. 路由层：TaskRouter.route()                                         │
│     ├─ 规则匹配 (关键词正则)    → rule signals                           │
│     ├─ SBERT语义匹配 (6维置信度) → sbert scores                         │
│     ├─ 融合决策 (scaling + 阈值 + 互斥)                                  │
│     └─ LLM兜底 (置信度不足时)                                            │
│     ── 输出：[("retrieve", 0.92), ("summarize", 0.78)]                  │
└─────────────────────────────────────────────────────────────────────────┘
  │
  ▼
┌─────────────────────────────────────────────────────────────────────────┐
│  3. 规划层：GraphGenerator.generate(tasks, question)                   │
│     调用DeepSeek → 生成TaskGraph DAG                                     │
│     ── 输出：{"nodes": [{"id": "1", "op": "hybrid_search", ...}, ...]} │
└─────────────────────────────────────────────────────────────────────────┘
  │
  ▼
┌─────────────────────────────────────────────────────────────────────────┐
│  4. 执行层：GraphExecutor.execute(graph)                               │
│     ├─ 拓扑排序遍历DAG                                                   │
│     ├─ 工具调度: hybrid_search → rerank → summarize                     │
│     ├─ 占位符解析: {{1}} → 节点1的结果                                   │
│     └─ 结果聚合                                                         │
│     ── 输出：{"1": [...docs...], "3": "...summary..."}                  │
└─────────────────────────────────────────────────────────────────────────┘
  │
  ▼
┌─────────────────────────────────────────────────────────────────────────┐
│  5. 响应层：返回 { answer, tasks, plan }                                │
└─────────────────────────────────────────────────────────────────────────┘
```

## 7. 架构演化对比分类

| 维度 | OLD 架构 (`last/core/`) | NEW 架构 (`content_core/`) |
|------|------------------------|---------------------------|
| **设计模式** | 单体模式 (Monolithic) | 管线模式 (Pipeline) + DAG |
| **路由** | 无 (所有请求相同流程) | 3层意图路由 (Rule→SBERT→LLM) |
| **执行** | 固定流水线 | 动态生成执行图 (LLM生成DAG) |
| **工具系统** | 硬编码 | 可注册工具 (ToolRegistry) |
| **向量存储** | LangChain Chroma (耦合) | 独立 VectorStore (解耦) |
| **嵌入模型** | BGE-M3 (大) | BGE-small-zh-v1.5 (小) + ONNX INT8 |
| **LLM调用** | OpenAI SDK (直接) | litellm (统一接口) |
| **文档加载** | LangChain loaders | (待迁移) |
